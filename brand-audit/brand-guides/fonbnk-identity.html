Fonbnk Identity Style Guide

Canonical brand specification. Rules stated here are definitive.

Colour

Our primary brand colour is Crisp Green #00B74F. RGB 0, 183, 79. Pantone 7481 C.

Our secondary colour is Charcoal Gray #53565A. RGB 83, 86, 90. Pantone Cool Gray 11 C.

Primary buttons and call to action fills use #00B74F.

Body text and supporting neutral tones use #53565A.

Typography

H1 headings and major editorial headlines are set in Freight Text Pro Medium.

Secondary headings are set in Objektiv Mk1 Medium.

Body copy is set in Objektiv Mk1 Regular.

Quotes are set in Freight Text Pro Book Italic.

UI

Buttons use an 8px corner radius.

Areas not defined

Photography style is not defined in this document.

Iconography is not specified.
